# Sabrina's Website

A personal frontend website built from scratch to showcase my frontend development skills, projects, and technical journey.

## 🌐 Project Overview

Sabrina's Website is a responsive frontend web project developed independently using HTML, CSS, and JavaScript.

The website was created to practice and demonstrate core frontend development skills, including webpage structure, responsive styling, user interface design, and JavaScript functionality.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ✨ Features

* Responsive frontend design
* Clean and structured user interface
* Personal projects showcase
* Interactive elements using JavaScript
* Organized HTML and CSS structure
* Mobile-friendly layout

## 🎯 Purpose

This project was built to strengthen my practical frontend development skills and create a personal space to showcase projects and technical experience.

It represents my hands-on experience with the fundamental technologies used in frontend web development.

## 📚 Skills Demonstrated

Through this project, I practiced:

* Semantic HTML
* CSS styling and layouts
* Responsive web design
* JavaScript functionality
* Frontend UI development
* Website structure and organization

Clone the repository:

```bash
git clone https://github.com/sabrin11643/sabrina-s-website.git
```
